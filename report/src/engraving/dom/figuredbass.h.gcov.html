      32              : /*---------------------------------------------------------
      33              : NOTE ON ARCHITECTURE
      34              : 
      35              : FiguredBass elements are stored in the annotations of a Segment (like for instance Harmony)
      36              : 
      37              : FiguredBass is rather simple: it contains only _ticks, telling the duration of the element,
      38              : and a list of FiguredBassItem elements which do most of the job. It also maintains a text with the
      39              : normalized (made uniform) version of the text, which is used during editing.
      40              : 
      41              : Normally, a FiguredBass element is assumed to be styled with an internally maintained text style
      42              : (based on the parameters of the general style "Figured Bass") FIGURED_BASS style and it is set
      43              : in this way upon creation and upon layout().
      44              : - - - -
      45              : FiguredBassItem contains the actually f.b. info; it is made of 4 parts (in this order):
      46              : 1) prefix: one of [nothing, doubleflat, flat, natural, sharp, doublesharp, cross]
      47              : 2) digit: one digit from 1 to 9
      48              : 3) suffix: one of [nothing, doubleflat, flat, natural, sharp, doublesharp, cross, backslash, slash]
      49              : 4) contLine: true if the item has a continuation line (whose length is determined by parent's _ticks)
      50              : and 5 parenthesis flags, one for each position before, between and after the four parts above:
      51              : each of them may contain one of [nothing, roundOpen, roundClosed, squaredOpen, squaredClosed].
      52              : 
      53              : There is a number of restrictions, implemented at the end of FiguredBassItem::parse().
      54              : Currently, no attempt is made to ensure that, if multiple parentheses are present, they are consistent
      55              : (matching open and closed parentheses is left to the user).
      56              : 
      57              : If an item cannot be parsed, the whole FiguredBass element is kept as entered, possibly un-styled.
      58              : If all items can be parsed, each item generates a display text from its properties,
      59              : lays it out so that it properly aligns under the chord, draws it at its proper location
      60              : and provides its FiguredBass parent with a normalized text for future editing.
      61              : 
      62              : FiguredBassItem has not use for formats (italics, bold, ...) and it is never edited directly;
      63              : more generally, it is never accessed directly, only via its FiguredBass parent;
      64              : so it is directly derived from EngravingItem and returns INVALID as type.
      65              : 
      66              : FiguredBass might require formatting (discouraged, but might be necessary for very uncommon cases)
      67              : and it is edited (via the normalized text); so it is derived from Text.
      68              : ---------------------------------------------------------*/
